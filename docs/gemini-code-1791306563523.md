### Expert Role
Senior Frontend Architect specializing in Next.js 15, React 19 state management (Zustand/Context), and strictly typed multi-tenant website builders.

### Objective
Fix the state leakage issue in the website builder's configuration sidebar. Ensure that when a specific section (e.g., Hero Section) is selected, the sidebar only displays its relevant options, and any modifications (like image uploads or typography alignment) apply strictly to that section without overriding global settings or other sections.

### Context & Background
- The application is a no-code clinic website builder for MedBook AI.
- Currently, updating an image or text alignment while a section is selected inadvertently updates other sections (e.g., uploading a Hero image replaces the About section image) or changes the global typography.

### Technical & Functional Requirements
1. **Active Section Scoping:** 
   - Ensure the left sidebar is strictly bound to the `activeSectionId`.
   - Render configuration inputs (image uploaders, alignment toggles) based ONLY on the schema of the currently selected section.
2. **Targeted State Updates:**
   - Refactor the update handlers to accept specific identifiers. Use a pattern similar to `updateSectionContent(sectionId: string, payload: Partial<SectionContent>)`.
   - Prevent any fallback to global state updates when a section-level property is being modified.
3. **Typography & Layout Isolation:**
   - Differentiate between `globalTheme.typography` and `section[id].styles.textAlign`. 
   - Apply section-specific alignment and typography classes (using Tailwind CSS 3.4 tokens) only to the wrapper of the target `sectionId`.

### Constraints
- **Zero UI/UX Regression:** Do not alter the visual design, layout, or design tokens of the builder. The UI must remain exactly as it is.
- **Strict Typing:** Ensure TypeScript interfaces correctly distinguish between global site config and individual section data structures.

### Deliverables
- The refactored state management logic (Context/Zustand store).
- The updated Sidebar component ensuring scoped property rendering and dispatched updates.
- The updated Canvas Section wrapper that correctly applies isolated styles.
