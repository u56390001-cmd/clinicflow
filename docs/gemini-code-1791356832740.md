* **Modal Header:**
  * Drag handle for mobile: `w-10 h-1 rounded-full bg-gray-300` (hidden on desktop).
  * Icon Badge: `MessageSquare` icon in `#4E5DB5` on `bg-[#EEF0FA]`.
  * Title: `Before we connect`.
  * Subtitle: `Choose how your clinic will use WhatsApp with the AI agent.`
* **Option Selection Cards (Radio Group behavior):**
  * **Option 1 (Dual Mode):**
    * Icon: `Phone` icon in `bg-gray-200`.
    * Title: `Use this number on WhatsApp App + AI agent`.
    * Description: `Continue using WhatsApp on your phone while the AI agent manages patient conversations, appointment bookings, and replies in the background.`
    * Radio Circle: Selection indicator.
  * **Option 2 (Dedicated AI Mode):**
    * Icon: `Zap` icon in `bg-gray-200`.
    * Title: `Use this number only with the AI agent`.
    * Description: `This number will be used exclusively by the AI agent and will not work on the WhatsApp mobile app.`
    * Helper text: `Suitable for a new or dedicated clinic number.`
    * Radio Circle: Selection indicator.
* **Warning Notice:**
  * `Info` icon with text: `You can change this setup later, but it may require reconnecting your number.`
* **Modal Footer Buttons:**
  * **Cancel Button:** `border border-gray-200 text-gray-600 hover:bg-gray-50 rounded-xl`. Closes the modal.
  * **Continue → Button:** Disabled state (`bg-gray-200 text-gray-400 cursor-not-allowed`) until an option is selected. When an option is selected, turns active (`bg-[#4E5DB5] text-white hover:opacity-90`). Clicking triggers Meta OAuth redirect flow.

## Technical & Component Architecture

### Required Files & State Management
1. **`app/(dashboard)/settings/whatsapp/page.tsx`**: Main page wrapper holding sidebar layout context.
2. **`components/whatsapp/WhatsAppSetupTab.tsx`**: Client component managing state:
   * `currentStep`: `1 | 2 | 3` (default: `1`).
   * `isConnected`: `boolean` (default: `false`).
   * `isModalOpen`: `boolean` (default: `false`).
   * `selectedMode`: `'app_and_ai' | 'ai_only' | null` (default: `null`).
3. **`components/whatsapp/BeforeConnectModal.tsx`**: Reusable modal component built using `@radix-ui/react-dialog` or Shadcn Dialog primitive.

### Code Implementation Standard
* Use Lucide React icons (`CircleAlert`, `MessageSquare`, `Info`, `Phone`, `Zap`, `CircleHelp`, `CircleCheckBig`, `ExternalLink`, `Shield`).
* Ensure total responsiveness across Mobile (`px-3`), Tablet (`px-6`), and Desktop (`px-8`).
* Include keyboard accessibility (`Escape` key closes modal, `FocusTrap` enabled).
