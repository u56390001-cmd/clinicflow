# Collapsible Left Sidebar - Top-to-Bottom Logical Order

The sidebar must be fully collapsible with a smooth CSS transition (`transition-all duration-300 ease-in-out`) and feature the following sections in exact sequential order:

### 1. Patient Identity & Quick Demographics (Top Panel)
- **Compact & High-Contrast Header**:
  - Patient Name (Bold, Slate-900) & MRN / Patient ID badge.
  - Demographics Row: Age, Gender, Weight (crucial for adult & pediatric dosing calculations).
  - Visit Badge: e.g., `First Visit`, `Follow-up`, `Token #2` (High-contrast solid badges).

### 2. AI Document Summary Panel
- **3-Line Executive Summary**:
  - Displays a concise 3-line clinical summary extracted from scanned patient documents (Overview tab integration).
  - Clean card layout with a subtle spark icon (`AI Overview`).

### 3. Current Vitals Summary (Read-Only + Edit Button)
- **Layout**: High-density 2-column grid (`grid-cols-2`).
  - `Row 1: BP | Pulse`
  - `Row 2: Temp | SpO2`
  - `Row 3: Weight | Blood Sugar`
- **Read-Only Display**: Clean numerical values with subtle unit labels.
- **Edit Action**: Include a small, clean `[Edit]` button in the card header that opens a mini inline edit form or modal so the doctor/assistant can update vitals if needed.

### 4. Scanned External Documents / OCR Medicines
- **List of Scanned Meds**: Displays medications extracted from patient-uploaded past prescriptions or documents.
- **Import Checkbox (`[☑]`)**: Toggling the checkbox automatically appends the medication into the main active prescription table.

### 5. Recent Labs & Diagnostic Reports
- **Report Summaries**: Compact list showing recent Blood Tests (CBC, LFT, RFT), X-Rays, and Ultrasounds.
- **Quick View Trigger (`[👁️]`)**: Eye icon button on each row that triggers a pop-up viewer for the PDF or report image.

### 6. Visit History & Past Notes (Bottom Accordion)
- **Timeline Summary**: Collapsible accordion showing past 2-3 visits.
- Displays previous `Chief Complaints` and `Diagnoses` for quick clinical context.
