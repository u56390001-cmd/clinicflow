- **Right Action Buttons**:

## 2. Left Panel: Patient Details & Interactive Vitals (1/3 Width)
- **Patient Details Card**:
  - Patient Name, Phone (`0321...`), Visit Date, Assigned Doctor (`Dr. Zayan Ahmed — Pediatrics`).
- **Patient Vitals Card (Interactive Editable Inputs)**:
  - Fields: Blood Pressure (`mmHg`), Pulse (`bpm`), Temperature (`°F`), SpO₂ (`%`), Respiratory Rate (`breaths/min`), Weight (`kg`), Height (`cm`), BMI (`kg/m²` - auto-calculated dynamically).
  - Include an **`[ Update Vitals ]`** button that triggers `upsertPatientVitalsAction` to update both the current prescription and the global patient vitals history.

## 3. Right Panel: Prescription Builder Workspace (2/3 Width)
- **Chief Complaint**: Multi-line textarea for patient's primary symptoms.
- **Clinical / Examination Findings**: Textarea for doctor's physical observations.
- **Diagnosis Section**:
  - Structured Diagnosis Tag selector + `Custom Diagnosis (Free Text)` input.
- **Medicines Table (Dynamic Row Builder)**:
  - Header: `"Medicines"` + **`[+ Add Medicine]`** button.
  - Table Columns:
    1. `Medicine Name` (Auto-complete search input)
    2. `Route / Form` (e.g., Oral, Syrup, Injection, Tablet)
    3. `Frequency` (e.g., 1-0-1, 1-1-1, Once Daily)
    4. `Duration` (e.g., 5 Days, 1 Month)
    5. `Instructions` (e.g., After meals, At bedtime)
    6. `Action` (Trash icon button to remove row)
- **Lab Tests Ordered**:
  - Header: `"Lab Tests Ordered"` + **`[+ Add Lab Test]`** button.
  - Dynamic list of test names with quick delete buttons.
- **Follow-Up & Doctor Notes**:
  - Follow-Up Date picker + Follow-Up Notes textarea.
  - Internal Doctor Notes (private clinical remarks).
