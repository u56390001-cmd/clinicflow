# UI/UX Overhaul Requirements

## 1. Top KPI Summary Ribbon (Compact Horizontal Layout)
- Replace the 4 huge empty cards with a single horizontal high-density summary ribbon (`bg-slate-50 border border-slate-200 rounded-xl p-3 grid grid-cols-4 gap-3`).
- Each item displays:
  - Small icon + Category Label (e.g., `Chronic Conditions`, `Past Surgeries`, `Family Risk Factors`, `Pending Approval`).
  - Active count badge + key tags (e.g., `2 Active` -> `DIABETIC`, `COPD` or `None on file` in muted text).

## 2. Medical History & OCR Entry List (Clean Card Hierarchy)
- **Header Row**:
  - Section title: `Medical History` with item counter badge.
  - Action Group: `[ Scan Document ]` | `[ Intake Link ]` | `[ + Add Entry ]`.
- **Item Cards Layout (`space-y-2.5`)**:
  - Replace stretched full-width boxes with structured border cards (`p-3.5 bg-white border border-slate-200 rounded-lg hover:border-slate-300 transition`).
  - **Title Row**: Test/Condition Name (e.g., `Thyroid mass`) in `font-semibold text-slate-900 text-sm` + status pills (`[Active]` green badge, `[✓ Verified]` teal badge, `[AI OCR]` amber badge).
  - **Description**: Clinical notes in `text-xs text-slate-600 line-clamp-2 mt-1`.
  - **Timestamp Metadata Grid (Crucial Requirement)**:
    - Display a dedicated footer row inside each entry card showing structured date-time badges:
      - 📅 **Doc Date**: `Original Date (e.g., 2014 or 12 Jan 2024)`
      - ⏱️ **Uploaded**: `Upload Date & Time (e.g., 18 Sep 2026, 04:30 PM)`
      - 🕒 **System Recorded**: `Current System Record Time`
  - **Quick Actions**: Trash / Delete icon on hover on the top right.

## 3. Past History Section (2-Column Read-Only Grid)
- **Eliminate Textarea Form Boxes**: Do NOT display static, empty `<textarea>` inputs for read-only history view.
- **Convert to 2-Column Masonry/Grid Layout**:
  - Grid sections: `Past Illnesses`, `Past Surgeries`, `Hospitalizations`, `Family History`, `Personal History`, `Immunization History`.
  - **Read-Only State**: Each section displays inside a neat card (`bg-slate-50/50 border border-slate-200 rounded-lg p-3.5`).
    - Heading: Bold category title with subtle left teal border accent.
    - Content: Concise bulleted text or clean paragraph (`text-slate-800 text-xs leading-relaxed`).
    - Empty State: Muted text `No history recorded` instead of giant empty input fields.
- **Edit Mode Toggle**:
  - Keep the **`[ 📝 Edit Health Info ]`** floating/header button.
  - Clicking `Edit Health Info` toggles a modal or expands inline clean input fields for updating records.
