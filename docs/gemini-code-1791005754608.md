# Role: Senior Lead Full-Stack SaaS Architect (Next.js 15 & Supabase Expert)

## Objective
Convert the static/placeholder "Public Booking Page Settings" UI into a fully functional, production-ready, multi-tenant module in MedBookAI/Cliniflow. The module must handle live booking toggle, custom slug management with real-time debounced availability validation, dynamic HD QR code generation/download, HTML website embed snippet generation, WhatsApp sharing, and booking slot rule configurations.

---

## Context & System Architecture
- **Application**: MedBookAI / Cliniflow (Multi-Tenant Healthcare EHR & Clinic Management SaaS).
- **Tech Stack**: Next.js 15 (App Router, Server Actions, React 19), TypeScript (Strict), Supabase (PostgreSQL, Auth, RLS), Tailwind CSS 3.4, Shadcn UI primitives, Zod validation.
- **Tenant Isolation**: Every database interaction MUST be scoped to the authenticated user's `clinic_id`.
- **Target Route**: Dashboard settings page (e.g., `app/(dashboard)/settings/booking/page.tsx`).

---

## Technical & Functional Requirements

### 1. Database Schema & Migration SQL
Ensure the `clinics` table supports public booking configuration. Provide an idempotent SQL migration script:
- `booking_slug` (VARCHAR, UNIQUE, INDEXED, NULLABLE/DEFAULT)
- `is_public_booking_enabled` (BOOLEAN, DEFAULT true)
- `slot_duration_minutes` (INTEGER, DEFAULT 15)
- `max_advance_days` (INTEGER, DEFAULT 7)
- `auto_approve_bookings` (BOOLEAN, DEFAULT true)
- Add necessary Supabase RLS policies for:
  1. Authenticated clinic members to UPDATE their own clinic booking settings.
  2. Public/Unauthenticated users to SELECT clinic details by `booking_slug` ONLY if `is_public_booking_enabled` is true.

### 2. Validation & Server Actions (`lib/actions/booking-settings.ts`)
Write typed Server Actions validated with Zod:
- `checkSlugAvailability(slug: string, currentClinicId: string)`:
  - Sanitizes input: lowercase, alphanumeric + hyphens only, min 3 chars, max 30 chars.
  - Returns `{ available: boolean, reason?: string }`.
  - Excludes the current clinic's own slug from collision check.
- `updateBookingSettings(data: BookingSettingsInput)`:
  - Validates `clinic_id` against current user session.
  - Updates `booking_slug`, `is_public_booking_enabled`, `slot_duration_minutes`, `max_advance_days`, `auto_approve_bookings`.
  - Revalidates path (`revalidatePath('/settings/booking')`).

### 3. UI Component Specs (`app/(dashboard)/settings/booking/page.tsx`)
Build a clean, responsive Shadcn-style UI featuring:

#### A. Live Status Card
- Toggle switch for "Booking page is live".
- Status indicator badge (Green "Live" / Gray "Disabled").
- Instant optimistic state toggle with background Server Action sync & Toast notification.

#### B. Custom URL / Slug Configuration Card
- Base domain display (e.g., `process.env.NEXT_PUBLIC_APP_URL` or `doxmate.in/book/`).
- Input field for custom slug with real-time 400ms debounced availability check.
- Visual feedback: Green checkmark with "Slug is available" or Red alert with "Slug is already taken".
- "Save Slug" button (disabled if slug is invalid or unchanged).

#### C. QR Code Generator & Download Card
- Render high-resolution QR code using HTML5 Canvas / `react-qr-code` pointing to `https://<domain>/book/<slug>`.
- "Download QR Code" button that exports a high-DPI PNG image formatted for reception desks, including Clinic Name and URL printed at the bottom.

#### D. Embed & Share Tools Card
- **HTML Embed Snippet**: Read-only `<textarea>` containing `<a href="..." target="_blank">Book an Appointment</a>` or responsive iFrame code with a 1-click "Copy Snippet" button.
- **WhatsApp Share**: Button generating `https://wa.me/?text=...` link containing the booking URL for instant messaging to patients.

#### E. Booking Slot Rules Card
- Dropdown select for `slot_duration_minutes` (10, 15, 20, 30, 45, 60 mins).
- Input number for `max_advance_days` (e.g., 1 to 30 days).
- Switch for "Auto-approve appointments".
