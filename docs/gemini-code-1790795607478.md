# Collapsible Left Sidebar - Top-to-Bottom Architecture

The sidebar must be collapsible (`transition-all duration-300 ease-in-out`) and organized in this exact order:

### 1. Patient Identity & Quick Demographics (Top Fixed Panel)
- **Compact & High Contrast Layout**:
  - Patient Name (Bold Slate-900) & Patient ID / MRN badge.
  - Demographics Row: Age, Gender, Weight (crucial for adult and pediatric dosage calculations).
  - Visit Badge: e.g., `First Visit`, `Follow-up`, `Token #2` (High-contrast solid badges).

### 2. AI OCR Summary Panel
- **Heading**: Change title strictly to **`AI OCR Summary`** (with a small clean AI spark icon).
- **Content**: 3-line clean executive summary extracted from patient uploaded documents/prescriptions.

### 3. Current Vitals Summary (Read-Only + Edit Action)
- **Grid Layout**: High-density 2-column grid (`grid-cols-2`).
  - `Row 1: BP | Pulse`
  - `Row 2: Temp | SpO2`
  - `Row 3: Weight | Blood Sugar`
- **Read-Only Display**: Bold values with clean unit badges.
- **Edit Trigger**: A small `[Edit]` button in the section header that opens a mini edit modal/form for doctor updates.

### 4. Scanned External Documents / OCR Medicines Container
- **Fixed Container with Max 4-5 Items**:
  - Show a MAXIMUM of 4 to 5 scanned OCR medications inside the sidebar container to prevent layout vertical distortion.
  - If total scanned medications exceed 5, render a **`[View All (X) Meds]`** button at the bottom of the card.
  - Clicking `[View All]` opens a clean, high-density **Dialog / Modal Popup** displaying the full list of OCR medicines.
- **STRICT Checkbox Logic (Verified vs Unverified)**:
  - If a medicine is **Unverified**: The selection checkbox MUST BE **DISABLED** (`disabled={!med.isVerified}`) and styled with a muted grey state. The user CANNOT check or import unverified medicines into Active Rx.
  - Only when a medicine is marked **Verified** (via checkmark button) does the import checkbox become active (`enabled`).
  - Checking an active checkbox immediately appends the verified medicine to the main Active Prescription Table.

### 5. Recent Labs & Diagnostic Reports Container
- **Fixed Container with Max 4-5 Items**:
  - Show a MAXIMUM of 4 to 5 recent Lab / X-Ray / Ultrasound reports (fetched from `patient_lab_reports` / patient documents history).
  - Format: Report Name, Date, and `[👁️]` Quick View icon.
  - If there are more than 5 lab reports, show a **`[View All Lab Reports]`** button that opens a detailed history **Modal Popup**.
- **Quick View Trigger (`[👁️]`)**: Opens a modal viewer displaying the PDF/Image of the selected lab report.

### 6. Visit History & Past Notes (Bottom Accordion)
- Collapsible accordion showing previous 2-3 visits' Chief Complaints and Diagnoses.
