# MASTER PROMPT: ClinicFlow EHR Integrations Dashboard Component Implementation

[EXPERT ROLE]
You are a Principal Full-Stack Engineer and System Architect specializing in Next.js 15 (App Router), React 19, TypeScript, Tailwind CSS, and Supabase Postgres with Row-Level Security (RLS).

[OBJECTIVE]
Implement a fully functional, production-ready, pixel-perfect, and error-free "Integrations Dashboard" page at `/app/(app)/integrations/page.tsx` for the ClinicFlow (MedBook AI) EHR application. The implementation must mirror the exact visual structure, layout, card designs, categories, filtering, search, toggle behaviors, modals, and toast interactions provided in the reference `integration_dashboard.html` mockup, while integrating seamlessly with Next.js 15 Server Actions and Supabase persistence.

[CONTEXT & TECH STACK]
- Framework: Next.js 15 (App Router), React 19, TypeScript (Strict)
- Styling: Tailwind CSS 3.4 with semantic tokens (`bg-canvas`, `bg-surface`, `primary`, `borderline`, `heading`, `bodytext`, `muted`, `activeGreen`)
- Icons: `lucide-react`
- Backend: Supabase (Postgres, SSR, Server Actions, Row-Level Security)
- Auth & Multi-Tenancy: Clinic context derived from current active clinic session (`clinic_members`)

[FUNCTIONAL & TECHNICAL REQUIREMENTS]

1. SUPABASE DATABASE MIGRATION (`supabase/migrations/0030_clinic_integrations.sql`)
   - Create table `public.clinic_integrations`:
     * `id` (UUID, PRIMARY KEY, DEFAULT gen_random_uuid())
     * `clinic_id` (UUID, NOT NULL, REFERENCES public.clinics(id) ON DELETE CASCADE)
     * `integration_key` (TEXT, NOT NULL) -- e.g. 'gcal', 'gmeet', 'gsheets', 'zoom', 'msteams', 'queue', 'whatsapp', 'smsgateway'
     * `status` (TEXT, NOT NULL, DEFAULT 'disabled', CHECK (status IN ('activated', 'disabled', 'locked')))
     * `config` (JSONB, DEFAULT '{}'::jsonb) -- stores API keys, sync frequency, etc.
     * `created_at` (TIMESTAMPTZ, DEFAULT now())
     * `updated_at` (TIMESTAMPTZ, DEFAULT now())
     * UNIQUE constraint on `(clinic_id, integration_key)`
   - Enable RLS on `public.clinic_integrations`.
   - Add RLS Policies allowing authenticated clinic members (`is_clinic_member(clinic_id)`) to SELECT, INSERT, and UPDATE records for their active clinic.

2. SERVER ACTIONS (`lib/actions/integrations.ts`)
   - `getClinicIntegrationsAction(clinicId: string)`: Fetch all persisted integrations for the given clinic ID.
   - `toggleIntegrationStatusAction(clinicId: string, integrationKey: string, status: 'activated' | 'disabled')`: Upsert integration status in Supabase and revalidate `/integrations`.
   - `saveIntegrationConfigAction(clinicId: string, integrationKey: string, config: Record<string, unknown>)`: Save JSON configuration (e.g. API keys, sync frequency) and revalidate `/integrations`.

3. DATA SEEDING / DEFAULT CONFIG
   If a clinic has no existing records in `clinic_integrations`, return default fallback data matching the HTML mockup:
   - Google Calendar (`gcal`): status = 'locked'
   - Google Meet (`gmeet`): status = 'locked'
   - Google Sheets (`gsheets`): status = 'disabled'
   - Zoom Consultations (`zoom`): status = 'activated'
   - Microsoft Teams (`msteams`): status = 'disabled'
   - Queue Management (`queue`): status = 'activated'
   - WhatsApp Reminders (`whatsapp`): status = 'disabled'
   - SMS Gateway (`smsgateway`): status = 'disabled'

4. COMPONENT STRUCTURE (`components/integrations/`)
   - `integrations-workspace.tsx` (Main client-side container with search, tab filtering, and category grid)
   - `integration-card.tsx` (Reusable integration card component supporting locked, disabled, and active states with toggle switch and detail/upgrade triggers)
   - `integration-config-modal.tsx` (Modal dialog to enter API Keys/Tokens and select Sync Frequency)
   - `integration-upgrade-modal.tsx` (Modal dialog prompting plan upgrades for locked features)

5. INTERACTIVE FEATURES & UI UX SPECIFICATIONS
   - Banner Header: Title "Integrations" and subtitle description.
   - Control Toolbar:
     * Filter Pills: "All Integrations", "Activated (count)", "Disabled". Smooth filtering without page reload.
     * Search Input: Real-time filtering by integration title and description text. Show "No integrations found" empty state if search matches zero cards.
   - Cards Layout:
     * Grid: 1 col on mobile, 2 cols on md, 3 cols on lg.
     * Header SVG icons matching the exact color themes (Blue for GCal/Sheets, Emerald for GMeet/WhatsApp, Sky for Zoom, Indigo for Teams, Red for SMS, Teal for Queue).
     * Line-clamp-3 descriptions.
     * Footer action bar showing status badge + button (Upgrade / Details / Connect / Toggle Switch).
   - Dynamic Activated Badge: Automatically recalculates count of active integrations.
   - Toast Feedback: Trigger toast notifications on toggle state change, settings saved, or upgrade redirect.
