# MedBook AI Psychology Workspace

# Mental Status Exam (MSE) Tab UX Improvement Prompt

## Task

Improve ONLY the Psychology Workspace → Mental Status Exam (MSE) Tab.

Do not modify: - Overview & Safety - Intake & History - Session Notes -
Psychometrics - Documents - Care Plan

## Goal

Create an AI-assisted clinical MSE workflow:

Psychologist observes patient → selects findings → adds notes → AI
generates structured summary → psychologist approves and saves.

------------------------------------------------------------------------

# UX Direction

Avoid: - Long paper-like forms - Excessive badges - Cluttered screens

Use: - Accordion sections - Checkbox / radio selections - Observation
notes - AI assistant panel - Clean clinical report output

------------------------------------------------------------------------

# MSE Sections

## Appearance

Options: - Neat - Disheveled - Unkempt - Poor hygiene - Bizarre -
Appropriate dress

Observation: Grooming, clothing, posture, physical appearance.

## Behavior & Attitude

Options: - Calm - Cooperative - Guarded - Agitated - Restless -
Withdrawn - Hostile - Suspicious - Hyperactive

## Consciousness

Options: - Alert - Drowsy - Lethargic - Stuporous - Unresponsive

## Orientation

Options: - Person - Place - Time - Situation

## Speech

Rate: - Normal - Slow - Rapid - Pressured

Tone: - Normal - Monotone - Loud - Soft

Quality: - Clear - Slurred - Incoherent - Hesitant

## Mood

Options: - Euthymic - Depressed - Anxious - Irritable - Elevated -
Angry - Hopeless - Fearful

Include patient's own words.

## Affect

Options: - Appropriate - Congruent - Restricted - Blunted - Flat -
Labile - Incongruent

## Thought Process

Options: - Logical - Linear - Circumstantial - Tangential - Flight of
ideas - Loose associations - Thought blocking - Perseverative

## Thought Content

Options: - Normal - Worries - Obsessions - Delusions - Paranoia -
Guilt - Hopelessness - Grandiosity - Suicidal thoughts - Homicidal
thoughts

## Perception

Options: - Normal - Auditory hallucination - Visual hallucination -
Tactile - Olfactory - Illusions - Derealization - Depersonalization

## Cognition

Include: - Orientation - Memory (Immediate, Recent, Remote) - Attention

Support MMSE/MoCA scores.

## Insight

Options: - Good - Partial - Poor - Absent

## Judgment

Options: - Intact - Good - Fair - Impaired - Absent

## Risk Assessment

Options: - No current risk - Suicidal thoughts - Suicide plan -
Self-harm - Harm to others

Notes: Intent, plan, means, protective factors.

## Functioning / ADLs

Options: - Independent - Needs support - Impaired

## Substance Use

Options: - None - Alcohol - Tobacco - Cannabis - Stimulants - Opioids -
Sedatives - Other

Details: Frequency, quantity, duration, last use.

## Additional Notes

Free clinical notes.

------------------------------------------------------------------------

# AI Features

Add AI assistance:

-   AI Draft
-   Improve wording
-   Summarize
-   Voice to Note

As psychologist selects findings, generate live clinical summary.

Example:

"Patient appeared cooperative with anxious mood, congruent affect,
logical thought process, intact cognition and no current safety risk
identified."

AI output requires psychologist approval before saving.

Mental Status Overview

Appearance: Normal Behavior: Cooperative Speech: Normal Mood: Anxious
Affect: Congruent Thought: Logical Cognition: Intact Insight: Good
Judgment: Intact Risk: Low
