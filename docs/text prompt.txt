# MedBook AI Psychology Workspace
# Overview & Safety Data Population Logic Prompt


## Goal

Improve the existing Psychology Overview & Safety tab.

Do not create new data entry fields.

The Overview & Safety tab should work as a clinical dashboard that automatically displays information collected from existing MedBook AI workflows.

It should not be manually filled by receptionist or psychologist.


---

# Data Flow Principle

Overview & Safety data should come from:

Patient Registration
+
Appointment Workflow
+
Pre-Visit Intake
+
Uploaded Documents
+
Psychometric Assessments
+
Session Notes
+
AI Processing


↓

Overview & Safety Dashboard


---

# AI Patient Summary

Populate from:

- Patient intake answers
- Uploaded documents
- Previous session notes
- Assessment results
- Patient history


AI should generate:

- Patient overview
- Main concern
- Relevant history
- Important clinical observations


Example:

Patient intake:
Anxiety + sleep problems

Document:
Previous therapy report

Assessment:
GAD-7 score


AI Summary:

"Patient presents with anxiety symptoms and sleep disturbance. Previous therapy history available."

---

# AI Rules

AI should not create unsupported clinical information.

AI summary must only use available patient data.

Show empty states when no data exists.


Example:

"No clinical information available yet.
Complete intake, upload documents, or record assessment to generate insights."


---

# Important

Overview & Safety is a read-only clinical summary dashboard.

Data entry should happen in:

- Intake & History
- Psychometrics
- Documents
- Session Notes
- Care Plan

Overview only displays processed information.
