# EXPERT ROLE: Senior Frontend UI/UX & Tailwind CSS Architect

## OBJECTIVE
Fix the dashboard layout overflow and scrolling architecture in MedBook AI (`clinicflow`). Ensure the left sidebar remains fixed, the main container occupies exactly the viewport height (`h-screen`), and individual content columns scroll independently without creating giant vertical white spaces at the bottom.

---

## CONTEXT & CURRENT ISSUES
- **Observed Bug:** The entire page is overflowing vertically with excessive blank white space at the bottom. Individual columns are not constrained to the viewport height, causing global body scrolling instead of localized, smooth column-level scrolling.
- **Design System:** Must strictly adhere to MedBook AI tokens in `tailwind.config.ts` — teal primary (#0D9488), slate secondary (#0F172A), light app background, and correct radius scale (cards 12px, controls 8px, pills 9999px)[cite: 3].

---

## TECHNICAL & LAYOUT REQUIREMENTS

1. **Root Viewport Constraint:**
   - The main dashboard layout wrapper must use `h-screen w-screen overflow-hidden flex flex-col` or `h-dvh flex flex-col` to lock the application inside the visible screen bounds.

2. **Left Sidebar (Navigation):**
   - Must be fixed in place on desktop: `w-64 h-full flex-shrink-0 border-r border-slate-200 bg-white` (or app background).
   - Should have independent internal scrolling if menu items exceed height: `overflow-y-auto`.

3. **Main Content Area & Header:**
   - Top header/navbar should be fixed at the top with a defined height (e.g., `h-16 flex-shrink-0`).
   - The content area below the header must use `flex-1 flex overflow-hidden` to fill the remaining vertical space.

4. **Independent Column Scrolling:**
   - Multi-column sections or tabs on the right side must be wrapped in a container with `flex-1 overflow-y-auto` or explicit height constraints (e.g., `h-[calc(100vh-4rem)]`).
   - Prevent any parent container from letting content expand infinitely downward. Use `overflow-y-auto` only on the specific inner panels/columns that need scrolling.

---

## DELIVERABLES
- Refactored layout component code using Tailwind CSS utility classes.
- Clean CSS flexbox/grid structures that guarantee zero unwanted vertical body scrollbars while allowing smooth inner-column scrolling.
