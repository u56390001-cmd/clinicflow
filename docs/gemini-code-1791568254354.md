Task 3: Server Authorization Guards & Audit Helper (lib/auth/role-guard.ts)
Implement runtime permission evaluation and audit logging helpers:

hasPermission(role: ExtendedRole, userOverrides: Record<string, boolean>, requiredPermission: Permission): boolean

Checks if user is owner (always true).

Checks custom userOverrides[requiredPermission] boolean if set.

Fallbacks to DEFAULT_ROLE_PERMISSIONS[role].

requirePermission(clinicId: string | undefined, requiredPermission: Permission)

Calls requireClinicContext(clinicId).

Validates user capability via hasPermission().

Throws ForbiddenError(403) if unauthorized.

logAuditEvent(params: { clinicId: string; userId: string; action: string; resourceType: string; resourceId?: string; details?: Record<string, any> })

Inserts audit log entry into public.audit_logs.
