CHOOSING THE RIGHT FILE
01_High_Resolution_Masters: use when exporting, designing or resizing. Transparent PNG with ample resolution.
02_Website_LandingPage_and_Dashboard: navbar (without tagline), website hero (tagline), dark-mode footer, dashboard sidebar and mobile header.

04_Favicons_App_Icons_and_Touch_Icons: browser tab, Android PWA, iOS touch icon and app shortcuts.
05_Monochrome_and_SingleColor: black, white, forest and sage flat logos; for printing and brand collateral.
06_Scalable_SVG_SingleColor_Traced: actual scalable, contour-traced single-color silhouettes; useful for vector printing. The SVG letterforms are outlines (not editable typed text).
07_Optimized_WebP_for_Websites: smaller web-ready versions (transparent).

NAMING RULE
- TRANSPARENT: transparent alpha channel and no fixed background.
- WHITE_BG, SOFT_SAGE_BG, ForestBG: opaque background included.
- NoTagline vs WithTagline: choose based on size and readability.
- dimensions AxB mean exact pixel size.

PRACTICAL BRAND NOTES
- Keep clear space around the logo (at least 10% of its displayed height).
- At small size, use icon only; don't force the tagline into navbar or favicon.
- Forest/dark text is for a light background; use the white variant over forest/dark backgrounds.
- SVGs are automatically traced from an image, not hand-crafted original vector artwork.
- The high-res PNGs are upscaled from the approved 2172x724 source. They are not fresh native-vector original artwork; fine typography detail is limited by the source image.
- The included original reference lets you compare the gradient rendering to the aligned brand-palette production variation.
- Brand-kit reproduction alone does not verify trademark uniqueness or exclusive rights.
