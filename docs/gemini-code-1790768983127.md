You are a Senior Frontend Engineer and UI/UX Expert working on **MedBook AI** (`clinicflow`), a Next.js 15 healthcare SaaS[cite: 2]. Your task is to build a world-class, high-density, minimal, and highly professional **Prescription Workspace** inside the `components/patients/record/tabs/prescriptions-tab.tsx` file.

# Strict UI/UX & Design Philosophy
The user has requested a massive UI upgrade based on these strict rules:
- **NO Gradients & NO Overlays**: Use solid, dynamic, high-contrast colors. (e.g., use solid `bg-teal-600` instead of teal gradients)[cite: 2].
- **Minimal & Compact**: Maximize screen real estate. Reduce padding where unnecessary. Use bold, highly readable typography for critical medical data.
- **Super Smooth Animations**: Use Tailwind's `transition-all duration-300 ease-in-out` for collapsing/expanding elements (especially the sidebar).
- **Design Tokens**: Strictly use MedBook AI tokens from `tailwind.config.ts` (Card radius `12px`, Input/Button radius `8px`, `bg-surface` for app background, `border-hairline` for borders)[cite: 2].

# Layout Architecture: 2-Column High-Density Workspace

## 1. Left Sidebar: Collapsible Clinical Context (30% Width when expanded)
- **Collapsible Behavior**: Add a toggle button (e.g., `PanelLeftClose` icon) to minimize the sidebar to just icons, allowing the main workspace to expand to 100% width. Use smooth width transitions.
- **Vitals Card (Compact Grid)**: 
  - Do NOT use a long vertical list. Use a dense 2-column grid.
  - E.g., `Row 1: BP | Pulse`, `Row 2: Temp | SpO2`, `Row 3: Weight | Blood Sugar`.
  - Typography: Clean, bold numbers with muted unit labels.
- **Previous Labs & Reports Card**:
  - A scrollable, minimal list of past ultrasound, X-ray, and lab reports.
  - Format: `[Eye Icon] Report Name - Date`. 
  - *Note: Do not include OCR-scanned medications here.*

## 2. Main Scrollable Workspace: The Rx Builder (70% Width)
This is a dedicated scrollable container (hide default scrollbar, use a custom minimal scrollbar).

- **Compact Clinical Inputs (Side-by-Side)**:
  - Place `Chief Complaint` and `Clinical / Examination Findings` in a **50/50 split grid** (`grid-cols-2`).
  - Use `TextareaAutosize` (or standard textareas with small default heights) so they start as 2 lines and expand smoothly as the doctor types, saving massive vertical space.

- **Active Prescription Table**:
  - **NEW Column Structure**: `[🔍 Medicine Search (Auto-complete)] | [Route] | [Dose] | [Frequency] | [Duration] | [Instructions] | [🗑️ Action]`
  - *Crucial Update*: The `Dose` column (e.g., 1 Tab, 2 Tabs, 5ml) is now separated from `Frequency` (e.g., Twice a day) for exact pediatric and adult calculations.
  - Table should have a minimal header and seamless row borders.

- **Previous Clinic Medications Container (1-Click Add)**:
  - Placed immediately below the Active Prescription Table.
  - Title: *"Past Prescribed Medications (This Clinic)"*.
  - Render a clean, scrollable list of medications prescribed in previous visits.
  - **Interaction**: Each row has a **Checkbox (☑)** or a **`[+]`** button. When clicked, it automatically copies that exact medicine (with its previous Route, Dose, Frequency, and Instructions) into the "Active Prescription Table" above.

- **Lab Tests Ordered**:
  - A single searchable input field that adds selected lab tests as dismissible pill tags below it.

## 3. Sticky Bottom Action Bar
- Remove the top header actions. Instead, place a fixed/sticky bar at the bottom of the main workspace container.
- **Left**: `[ Load Template ]` dropdown.
- **Right**: `[ Print Preview ]` (ghost/outline button) and **`[ Complete & Next Patient ]`** (solid `bg-teal-600 text-white font-medium hover:bg-teal-700`)[cite: 2].
