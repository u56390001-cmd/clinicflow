## 3. MAIN WORKSPACE: PRESCRIPTION CONTAINER (70% Width)
Wrapped inside a high-contrast container with custom scrollbar.

### A. Compact Side-by-Side Clinical Inputs
- `Chief Complaint` and `Clinical / Examination Findings` placed in a **50/50 split grid** (`grid-cols-2`).

### B. Active Prescription Table Container
- Table Columns:

- Title: *"Past Prescribed Medications (This Clinic)"*.

- Each item has a **`[+] Add` Checkbox**. Toggling it immediately copies the medicine, dose, frequency, and instructions into the Active Prescription Table above.

### D. Lab Tests Ordered
