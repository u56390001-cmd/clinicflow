# MASTER TECHNICAL SPECIFICATION: Bottom-Anchored Dynamic Hero Section Image Layout

## Expert Role
You are a Senior Frontend Engineer and UI/UX Developer specializing in Next.js 15, React, and Tailwind CSS layouts.

## Objective
Fix and refactor the Hero Section layout so that a transparent (no background) 4:5 aspect ratio doctor image anchors seamlessly to the bottom edge of the hero container, scaling dynamically and filling vertical space without looking small or floating.

## Context & Problem Statement
Currently, a 4:5 ratio doctor image is rendered too small on the right column of a 2-column hero section. We need to match high-converting health platform landing pages (like ProHealth) where the hero image rests directly on the bottom container border (`items-end`) and fills the vertical height dynamically.

## Key Layout Requirements
1. **Container Alignment:**
   - Hero container must use `grid grid-cols-1 lg:grid-cols-12` or `flex flex-col lg:flex-row`.
   - Minimum hero height: `min-h-[80vh]` or `min-h-[600px]` on desktop.
   - Set `overflow-hidden` on the outer hero wrapper to ensure clean bottom masking.

2. **Right Column (Image Container):**
   - Must use `h-full flex items-end justify-center lg:justify-end relative`.
   - Image wrapper must extend to the bottom edge of the section with zero bottom padding.

3. **Image Element Styling (4:5 Ratio Optimization):**
   - Set classes: `h-full max-h-[500px] lg:max-h-[650px] w-auto object-contain object-bottom select-none`.
   - Ensure image aspect ratio (4:5) is maintained without stretching or horizontal compression.

4. **Floating UI Overlay Elements (Optional):**
   - Position absolute badges (e.g., "150K+ Patient Recoveries", "870+ Verified Doctors") floating around the top-left and right sides of the doctor cutout with backdrop-blur.
