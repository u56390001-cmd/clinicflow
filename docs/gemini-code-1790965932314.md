## REAL-TIME & AUDIO ARCHITECTURE REQUIREMENTS

### 1. Audio Announcement Engine (`utils/audioAnnouncer.ts`)
- **Synthesized Chime:** Implement `playDigitalChime()` using HTML5 `AudioContext` (frequency transition 523Hz -> 659Hz) to avoid requiring external MP3 assets.
- **Speech Synthesis (TTS):** Implement `speakAnnouncement(token, patient, doctor)` using `window.speechSynthesis`.
  - Speech Text: `"Token Number ${token}, ${patient}, please proceed to ${doctor}'s consultation room."`
  - Speed: `0.85` pitch/rate for clean public address clarity.

### 2. WebSocket Realtime Sync (`hooks/useQueueSocket.ts`)
- Connect to socket room `clinic:{clinicId}:queue`.
- On receiving `QUEUE_UPDATED` event payload:
  1. Dynamically re-render `currentPatient` and `upcomingQueue` lists without page reload.
  2. If `tokenChanged === true`, invoke chime + speech announcement automatically.
- Include exponential backoff reconnection handling for network fluctuations.

### 3. Autoplay Permission Overlay
- Render a transparent floating overlay banner on first load: `"🔊 Click anywhere or tap screen to activate Audio Announcements"`.
- User interaction initializes `AudioContext.resume()` and unlocks TTS.
