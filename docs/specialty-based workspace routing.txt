# Objective

Implement specialty-based automatic doctor workspace routing.

The system should automatically open the correct clinical workspace based on the logged-in doctor's specialty.

DO NOT add extra setup steps for admins.

DO NOT ask admin to manually select workspace.

Doctor Specialty should automatically determine workspace.
