[DYNAMIC DATA & DATABASE REQUIREMENTS]
All data MUST be dynamic. Fetch or derive from the following Supabase tables:
1. `patients`: `patient_code`, `full_name`, `age`, `gender`, `blood_group`, `height_cm`, `weight_kg`, `known_allergies`, `medical_conditions`
2. `vitals`: Most recent and historical vitals (`bp_systolic`, `bp_diastolic`, `pulse_rate`, `temperature_f`, `spo2`, `recorded_at`)
3. `prescriptions`: Most recent encounter record (`chief_complaint`, `diagnosis`, `medicines` JSON, `created_at`, `doctor_id`)
4. `visits`: `visit_count`, `last_visit_date`, `status`, `consultation_start_time`
5. `patient_bills`: Current visit billing status (`paid` vs `pending_amount`)
6. `patient_documents`: Unreviewed lab reports/documents count (`status = 'pending_review'`)
